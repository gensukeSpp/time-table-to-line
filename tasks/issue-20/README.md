## この Issue のスコープ（再掲）

**スコープ内（タイムライン詳細モーダル）**
1. タイムライン上のイベントクリックで詳細モーダルを呼び出す（`react-calendar-timeline` の `onItemClick`）
2. **グループ管理者**が他メンバーのイベントを開いたとき、**更新 / 削除ボタンを表示しない**読取専用表示（メンバー名・タイトル・内容・進捗）
3. クリックしたイベント付近に**タイムラインへ重ねて**表示（絶対配置オーバーレイ、縦スクロール不要）
4. `src/components/organisms/InputItem.tsx` AddChildForm を使い回す（`readOnly` プロップ追加）
5. admin 操作は `{admin & ...}` / `{admin ? ... : ...}` で対応

**スコープ外（本 Issue ではやらない）**
- Calendar（個人）画面への変更（既存 `AddChildForm` の挙動を壊さない）
- イベントの更新 / 削除 API 自体の追加（既存 `useUpdateEventMutation` / `useDeleteMutation` を再利用）
- バックエンド変更
- マイルストーン関連

## 受け入れ要件（Issue #20）

1. **グループ管理者**がタイムライン上のメンバーのイベントをクリックすると詳細モーダルが呼び出され、そのとき**更新 / 削除ボタンが表示されない**
2. 自分のイベントをクリックした場合は、従来どおりの表記（更新 / 削除ボタンあり）で良い
3. 詳細モーダルはクリックしたイベント付近に重ねて表示され、縦スクロールを強要しない

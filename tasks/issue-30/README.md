## スコープ
### 実装するもの
- 対策 1: `.rbc-event-allday`（フルデイイベント）をデフォルト色 `#3174ad` から区別できる色（赤・紫系統から離れ、白抜き文字がはっきりする色）にする
- 対策 2: 'month' ビューでフルデイイベント以外（時間ごとのイベント）の **ドラッグ（移動）と伸縮（リサイズ）を不可** にする。`draggableAccessor` / `resizableAccessor` で実現（前者が可能なので、ダイアログ方式は採用しない）
- 対策 3: 'month' ビューのリサイズで「隣スロットのイベントに EW アンカーが遮られて掴めない」問題を、EW アンカーのヒット領域拡大 + z-index で解消
- 現行 `CalendarView.tsx:34-51` の「自他判定」`eventPropGetter` が実は機能していないため、**削除・書き換え**（issue の要調査項目への回答）

### 対象外
- ドラッグ・アンド・ドロップ操作で `start_time` / `end_time` へ反映する実装（issue スコープ外。今後の DnD 反映タスクで扱う）
- 対策 2 の「後者（確認ダイアログ）」と、ダイアログ OK 時に週ビュー `.rbc-row` へ移す処理（`start_time: 0:00 / end_time: 23:59` へ変更）→ **Issue #31 で実装**
- 真の日跨ぎイベント作成 UI / バックエンド・DB 変更

- 'week' ビューでのドラッグ・アンド・ドロップ操作に支障が出ていないか

# PR #33 改善提案 2 — 隣接イベントの EW リサイズ回帰テスト

参照: `.github/reports/pr-33-review.md` 改善提案 2

## 目的

既存の accessor テストだけでは保証できない、react-big-calendar の実 DOM における EW アンカー生成を回帰テストで確認する。隣接イベントの両方に左右アンカーが残ることを確認し、改善提案 1 の CSS 調整でリサイズ対象の構造が壊れていないことを固定する。

## 計画

1. `Calendar.spec.tsx` の実 RBC レンダリング経路を利用する。
2. 同一日の連続するフルデイイベントを用意し、month ビューでレンダーする。
3. 各イベント要素に左右 EW アンカーが 1 個ずつ存在することを、イベントタイトルとの対応で検証する。
4. 実ブラウザでの「左イベント右端」「右イベント左端」の個別操作は手動受け入れ確認としてテスト計画に記録する。
5. 対象テストと品質ゲートを実行する。

- [x] 各隣接イベントの左右 EW アンカー生成を検証する。

## 検証範囲

- 自動テスト: RBC が隣接イベントごとに `rbc-addons-dnd-resize-ew-anchor` の左右アンカーを生成すること。
- 手動確認: 隣接境界の数ピクセル範囲で、左イベントの右端と右イベントの左端をそれぞれ操作できること。

## 実施結果

- `Calendar.spec.tsx` に month ビューの連続するフルデイイベントを追加した。
- 各イベントの実 DOM に左右 2 個の EW アンカーが生成されることを検証した。
- 手動確認項目を `test-plan.md` に追加した。 → **10px 化と DOM 回帰テストでリスク軽減。境界操作は実ブラウザ確認済み**

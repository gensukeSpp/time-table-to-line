# PR #33 改善提案 1 — EW アンカー領域の衝突回避

参照: `.github/reports/pr-33-review.md` 改善提案 1

## 目的

隣接するフルデイイベントの境界で、左イベントの右 EW アンカーと右イベントの左 EW アンカーが同じヒット領域を奪い合わないようにする。イベント幅や日セルの配置は変更せず、アンカーの内側ヒット領域だけを必要最小限にする。

## 計画

1. 現行の `.rbc-addons-dnd-resize-ew-anchor` CSS と react-big-calendar の既定配置を確認する。
2. 左右アンカーが各イベント内部に収まり、隣接イベントとの共有境界を越えない幅へ調整する。
3. 左右両方のアンカーが生成される隣接イベントの実 DOM テストを追加し、イベント幅の変更やアンカー削除が起きていないことを固定する。
4. lint、対象テスト、全テスト、build を実行する。

## タスク

- [x] EW アンカーの幅を共有境界で衝突しない寸法に調整する。
- [x] 隣接イベントの左右アンカーが各イベントに生成される実 DOM テストを追加する。
- [x] 対象テストと品質ゲートを実行する。
- [x] 実ブラウザで隣接境界の左右リサイズ操作を確認できる受け入れ項目を記録する。

## 実装方針

- `CalendarView.css.ts` のグローバル CSS のみを変更する。
- イベント本体の `width`、`left`、`right`、日セルのグリッド配置は変更しない。
- アンカーはイベントの左右端からイベント内部へ入る領域として扱い、左右イベントの領域が共有境界をまたがない値にする。

## 実施結果

- `CalendarView.css.ts` の EW アンカー幅を `20px` から `10px` に変更した。
- `10px` は各イベント内部に収まり、隣接イベントの共有境界をまたがない寸法とした。
- 実ブラウザでの境界操作は手動受け入れ確認として残している。

## スコープ内
- 'month' ビューのスロットクリック → タイトル追加ダイアログ → **フルデイ（0:00 〜 23:59:59）イベント** で追加
- 作成されたイベントを 'month' ビュー由来と区別できるようにする（`start_time: 0:00`, `end_time: 23:59` の時刻パターンで識別）
- 'month' ビューで作成したイベントが、**日を跨がなくても** 'week' ビューの `.rbc-row`（上部バンド）に表示され、`.rbc-event-allday` クラスが付与される
- フロントエンドのみ（`../time-table-to-line`）。バックエンド・DB スキーマ変更なし

## スコープ外（issue #29 で明示）
- 'month' ビューでのドラッグ&ドロップによるイベント伸縮の正確な挙動（現在「形式的には操作可能」）
  - 縮小で 12:00AM に戻される問題（`.rbc-event-allday` 付与で解消に至る可能性はあるが、動作検証の対象とし、**仕上げの対象外**）
  - `start_time`, `end_time` に期待する日時が入ること（受け入れ要件の対象）
- 真の日跨ぎイベント（例: 23:00 開始・翌日 0:30 終了）の作成専用 UI（YAGNI）

## 受け入れ要件（issue 原文より）
1. 'month' ビューと 'week' ビューで、**区別されてイベントが追加される**こと（`start_time`, `end_time` の違い）
   - 'month': `start_time: 0:00`, `end_time: 23:59`
   - 'week': 従来どおり（クリック時刻 ～ +1h / 23:00 は同日 23:59:59 に丸め）
2. 'month' ビューで作成されたイベントは、**日を跨がなくても 'week' ビューでは `.rbc-row` に表示される**こと
3. （実装要件）'month' ビューで作成されたイベントは `.rbc-row .rbc-row-segment` の子に **`.rbc-event-allday`** が付与されること（次 Issue #30 での区別に利用）

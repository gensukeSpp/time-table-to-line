## スコープ

**スコープ内（フロントエンドのみ。バックエンド変更なし）**
1. マイルストーン詳細モーダル（`MilestoneDetailDialog`）を **全ユーザーが閲覧可能** にする
   - 現在は非管理者は詳細を開けない（クリック不可・モーダル非表示）
   - 閲覧は誰でも可、**編集（タイトル/説明/日付の更新）は管理者のみ**
2. タイムラインのイベント詳細表示（`EventDetailOverlay` → `AddChildForm` 閲覧専用）に
   周囲余白（padding）を追加し見栄えを整える

**スコープ外**
- バックエンド `/milestone/*` の変更（閲覧権限はフロント表示制御のみで対応。バックエンドは
  `/milestone/all` が open/waiting を返す既存挙動のまま）
- マイルストーン作成 / close / 削除の権限変更
- `AddChildForm` の編集ロジック変更

## 受け入れ要件

1. 非管理者でもマイルストーン一覧のタイトルをクリックして詳細モーダルが開く
2. 非管理者に詳細モーダルで「タイトル / ステータス / 作成者名 / グループ名 / 説明 /
   ガイドライン終了日 / 達成日」が読取専用表示される
3. 非管理者には更新ボタン・入力欄が表示されず、変更できない
4. 管理者は従来どおり詳細モーダルで編集（更新）できる
5. タイムラインのイベント詳細表示（`AddChildForm` 閲覧専用）の周囲に余白が付く
6. `bun run lint`（--max-warnings 0）・`bun run build`・`bun run testrun` が通る
7. `console.log` を新規に残さない

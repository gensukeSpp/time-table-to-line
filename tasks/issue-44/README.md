## この Issue のスコープ（再掲）

### スコープ内（修正 3 点）

1. **マイルストーン作成フォームのリセット** — マイルストーンを続けて作成したとき、前回の内容（タイトル / 説明 / 目安日付）がフォームに残らないようにする。
2. **イベント `progress` の null 復帰** — 一度値を入れた `progress` を「未定（null）」へ戻せるようにし、配色をデフォルト `#3174ad` へ戻す。
3. **仕様変更: 同グループメンバーへのイベント詳細閲覧緩和** — 非管理者でも、自身以外のイベントをクリックすると詳細モーダル（閲覧専用）が現れるようにする。

### スコープ外

- マイルストーン CRUD・詳細モーダル（既存のまま。閉じたマイルストーンの一覧 `GET /milestone/closed` は Issue #41 で実装済みのため対象外）。
- イベントの**編集権限**（更新 / 削除）は従来どおり**自分のイベントのみ**（`AddChildForm` の `isOwnEvent` 制御のまま）。閲覧のみ緩和する。
- イベント詳細モーダルの見た目・レイアウト変更。
- `progress` の配色パレット変更（`src/lib/progressColor.ts` の定数は変更しない。null 時のデフォルト `#3174ad` は既存実装で充足）。

## 受け入れ要件（Issue #44）

1. マイルストーン作成直後、「マイルストーン作成」ボタンで現れるフォームが**空**であること
2. `progress` を null に戻して、配色も `#3174ad` に変更されること
3. 非管理者でも、自身以外のイベントをクリックすると、詳細モーダルが現れること

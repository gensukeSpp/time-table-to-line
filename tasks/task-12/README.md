## スコープ

**対象**
- タイムラインの `itemRenderer`（`src/components/pages/TimelinePage.tsx`）のマイルストーン配色処理

**対象外**
- バックエンド変更なし
- Calendar ビューの配色・イベントフォーム変更なし
- マイルストーンの CRUD / 状態遷移ロジック変更なし
- 配色の数値・仕様（10 固定色 / デフォルト #2196f3 / クリック後 #ffc107）変更なし

## 受け入れ要件

1. マイルストーン所属イベント（open / waiting 双方）をクリックすると選択色 `#ffc107` になる。
2. 別のイベントをクリックして選択解除した際、そのマイルストーン所属イベントは**自身のマイルストーン色**（open `#009688` / waiting `#9c27b0` + opacity 0.7）に戻る（デフォルト `#2196f3` にならない）。
3. 未所属イベントは選択解除後 `#2196f3`、クリック中は `#ffc107` のまま。
4. 初回表示（未選択状態）は従来どおりマイルストーン色が正しく付く。
5. `bun run lint` / `bun run build` / `bun run testrun` が通る。

1. クリック対象をタイトルのみに
src/components/organisms/MilestoneListTitle.tsx — それまで色バー・タイトル全体を包んでいた UnstyledButton(クリック領域)を、タイトル テキストのみに限定しました。色バー(colorBar)と waiting 日の「MM/dd close」はクリック対象外です(色バーは別用途で使用予定という方針ど おり)。

tsx
```typescript
<Box className={item}>                     // 行全体（非クリック）
  <Box className={colorBar} ... />         // 色バー：別用途用（非クリック）
  {closedLabel && <Text>... close</Text>}  // waiting 日（非クリック）
  <UnstyledButton className={titleButton} onClick={...}>  // タイトルのみクリック可
    <Text>{milestone.title}</Text>
  </UnstyledButton>
</Box>
```


2. タイトルをボタン様に浮き上がらせる
src/components/organisms/MilestoneList.css.ts に titleButton スタイルを追加しました。

- 通常時: 淡いグラデーション背景(#fafafa → #eceff1) + 細いボーダー + 下向き投影の box-shadow → 浮き上がった 3D ボタン風
- ホバー時: 背景を明るくし影を強く → さらに持ち上がる
- 押下時: 影を沈め translateY(1px) → ボタンが沈み込む押下感

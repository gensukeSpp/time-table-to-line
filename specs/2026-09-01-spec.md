今後メンバー人数が増えて表示位置が気になる場合は、computeOverlayPos（src/components/pages/TimelinePage.tsx 冒頭）を調整すればすぐ対応できます。要点を整理しておきます：

- 位置の挙動: クリックしたイベントの直下（item.bottom + 8px）に重ねて表示。コンテナ下端（cont.height - 220px）と右端（cont.width - 340px）を超えないようクランプ
- 人数が多いときの懸念: イベントをクリックすると下方向に 220px 幅の領域を占有するため、縦スクロールが必要になる可能性。対策例は item.bottom 上端起点 + zIndex 優先で下方に重ねる、Math.min(...) を廃止してオーバーレイを右上固定にする、など
- currentTarget 対策: React 19 等で e.currentTarget が null の場合、フォールバック（{top:12, left:12}）に倒れる

万一調整が必要になったら教えてください。既存の単体テスト（src/tests/InputItem.spec.tsx）と品質ゲート（build / test / lint）を維持し たまま、位置ロジックだけ調整します。
